# Code Of Conduct

This repository is maintained as a focused contest/demo project. Keep discussion practical, respectful, and tied to the game, documentation, security, or Devpost submission surface.

## Expected Behavior

- Be direct and constructive.
- Use issues and PRs for reproducible reports or concrete improvements.
- Respect the current scope guardrail: one playable case, mobile browser, live AI suspect dialogue, deterministic engine.
- Avoid posting secrets, personal data, or private provider credentials.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Public disclosure of vulnerabilities or secrets.
- Spam, unrelated promotion, or deliberately misleading claims about project capabilities.

Maintainers may close, edit, or remove comments and issues that violate this code of conduct.
