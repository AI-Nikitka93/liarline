# Support

Liarline is a Devpost AI Game Week demo repository.

## Where To Ask

- Reproducible gameplay, mobile UI, localization, or fallback bugs: open a bug report issue.
- Future gameplay ideas: open a feature request issue.
- Public copy, README, Devpost wording, or claim accuracy: open a docs update issue.
- Vulnerabilities or leaked secrets: follow `SECURITY.md` and do not open a public issue.

## Useful Details For Bugs

Include:

- browser and device/viewport;
- locale selected in the game;
- whether a Groq key was configured;
- whether the answer was live AI or fallback;
- the command or route used to reproduce the issue.
